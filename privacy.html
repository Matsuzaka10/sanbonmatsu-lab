Privacy Policy

Last updated: November 14, 2026

"physics-shorts uploader" (the "Tool") is a private tool used only by the owner of the YouTube channel sanbonmatsu lab (@sanbonmatsulab) to publish its own videos to its own YouTube channel and Instagram account.

YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is also subject to the Google Privacy Policy.

Information accessed, collected and stored

  • With the owner's permission (OAuth scopes youtube.upload and youtube.readonly), the Tool uploads videos to the owner's own channel and reads basic information and view statistics of the owner's own channel and videos.
  • The Tool stores only: the owner's OAuth refresh token (encrypted, in GitHub Secrets) and view statistics of the owner's own videos (in a private repository).
  • The Tool does not access, collect or store any data of other YouTube users or viewers, and does not use cookies or tracking.

How information is used and shared

Information is used only to publish the owner's videos and to measure how they perform. It is never shared with, sold to, or transferred to any third party. The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

  • Access can be revoked at any time via the Google security settings page. After revocation, the stored refresh token no longer works and is deleted from GitHub Secrets.
  • Stored statistics are kept only while the Tool is in use and are deleted within 30 days after the Tool stops being used or upon request.
  • Statistics obtained from YouTube API Services are refreshed or deleted at least every 30 days.
